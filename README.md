# 🎙️ Voice Dictation — голосовой ввод без интернета

[![Python](https://img.shields.io/badge/python-3.9%2B-blue)](https://www.python.org/downloads/)
[![Vosk](https://img.shields.io/badge/движок-Vosk-orange)](https://alphacephei.com/vosk/)
[![License](https://img.shields.io/badge/license-MIT-yellow)](LICENSE)
[![Tests](https://img.shields.io/badge/tests-28%20passed-brightgreen)]()

Диктуете — получаете текст. Распознавание идёт **на вашем компьютере**:
звук никуда не отправляется, интернет нужен один раз, чтобы скачать модель.

```text
  ⌨️ Ctrl+Alt+Пробел      🎙️ речь        📝 текст
        (удерживать)  ──►  ▁▃▅▇▅▃▁  ──►  «Привет, как дела?»
                            уровень          ↓
                          микрофона     буфер обмена + история
```

## ✨ Возможности

- **Полностью оффлайн** — модель Vosk работает локально
- **Русский и английский** — переключение прямо в окне
- **Горячая клавиша** `Ctrl + Alt + Пробел` — работает в любом приложении
- **Знаки препинания голосом** — «точка», «запятая», «новая строка», «абзац»
- **Заглавные буквы** расставляются сами: «привет как дела точка» → «Привет как дела.»
- **Автокопирование** в буфер обмена
- **История** — всё надиктованное сохраняется, случайно затёртое можно найти
- **Настоящий уровень звука** — видно, слышит ли вас микрофон

## ⚙️ Установка

```bash
git clone https://github.com/Artpardsur/voice_dictation.git
cd voice_dictation
pip install -r requirements.txt

# Скачать модель распознавания (около 45 МБ)
python download_models.py ru

python main.py
```

Модели не лежат в репозитории: обе весят больше 150 МБ, и клонирование
из-за них тянулось минутами. `download_models.py` скачивает их с сайта Vosk
и распаковывает в `models/`.

```bash
python download_models.py           # обе модели
python download_models.py ru        # только русскую
python download_models.py --list    # что уже установлено
```

## 📝 Как пользоваться

1. Запустить `python main.py`
2. Удерживать **Ctrl + Alt + Пробел** и говорить
3. Отпустить — текст появится в окне и сразу окажется в буфере обмена
4. Вставить куда угодно обычным **Ctrl + V**

Кнопка «🎤 НАЧАТЬ ЗАПИСЬ» делает то же самое мышью.

### Знаки препинания голосом

| Сказать | Получится |
|---|---|
| точка | `.` |
| запятая | `,` |
| вопросительный знак | `?` |
| восклицательный знак | `!` |
| двоеточие | `:` |
| точка с запятой | `;` |
| тире | `—` |
| открыть скобку / закрыть скобку | `(` `)` |
| новая строка | перевод строки |
| новый абзац | пустая строка |

Команда срабатывает только как отдельное слово: «заточка» останется
заточкой, а не превратится в «за.».

## 🧱 Структура

```text
voice_dictation/
├── main.py                # запуск
├── download_models.py     # скачивание моделей Vosk
├── src/
│   ├── recognizer.py      # микрофон и Vosk
│   ├── textproc.py        # знаки препинания и заглавные буквы
│   ├── models.py          # где лежат модели и как их получить
│   ├── database.py        # история надиктованного
│   ├── hotkey.py          # глобальные горячие клавиши
│   └── clipboard.py       # буфер обмена
├── ui/main_window.py      # окно на CustomTkinter
├── experiments/           # ручные пробы микрофона и модели
└── tests/                 # 28 проверок, без микрофона и модели
```

История лежит в `%LOCALAPPDATA%\VoiceDictation\history.db` — не в папке
программы, поэтому переустановка её не сотрёт.

## 🧪 Тесты

```bash
pip install pytest
python -m pytest
```

Проверяются знаки препинания, заглавные буквы, склейка кусков речи, история
и пути к моделям. Микрофон и модель не нужны — всё это чистая обработка
строк и работа с базой.
