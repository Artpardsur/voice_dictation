# Ручные пробы

Черновые скрипты, которыми проверяли микрофон и модель Vosk вживую:
какие устройства ввода видит система, что распознаёт модель на живой речи.
Они открывают микрофон и требуют присмотра — это не тесты, а записи проверок.

Раньше они лежали в `tests/`, и `python -m pytest` выполнял их код при сборе
тестов: программа лезла в микрофон посреди прогона.

Запускать по одному:

```bash
python experiments/test_mic.py
```

Автоматические проверки — в папке [`tests/`](../tests).
